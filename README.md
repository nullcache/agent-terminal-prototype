# Agent 终端输出原型

这是一个独立的 Go 原型，用来验证 Agent 工具输出进入模型上下文前，如何清理终端控制序列和进度条刷新。工具从标准输入读入数据，将清理后的文本写到标准输出。

## 运行

需要 Go 1.26。项目仅使用标准库。

```sh
printf '开始\r\n10%%\r50%%\r\033[32m100%%\033[0m\r\n完成\n' | go run .
go test ./...
```

预期输出为三行，依次是「开始」「100%」「完成」。

## 实现范围

- 移除常见的 ANSI CSI 和 OSC 序列，包括颜色、清屏、窗口标题和终端超链接序列。
- 识别 CRLF。遇到单独的回车时，同一行后续的可见文本会替换之前的进度内容，已换行的日志会保留。
- 以单字节分段输入测试状态机，覆盖 UTF-8、回车刷新和转义序列跨读取边界的情况。

原型采用整行替换语义。光标定位、局部覆盖和其他终端渲染语义超出当前范围。PTY 会话和进程信号转发、macOS 与 Linux 沙盒、MCP 并发文件写入均处于设计范围，当前仓库只实现输出清理环节。
